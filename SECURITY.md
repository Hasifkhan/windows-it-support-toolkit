# Security Policy

## Reporting a Security Issue

If you discover a security issue involving this toolkit, please do not publicly disclose sensitive details before the issue has been reviewed.

Contact the project owner privately through the contact information provided on the author's GitHub profile.

## Important

Before reporting an issue, verify that it is actually related to the toolkit and include:

- Windows version
- Toolkit version
- Reproduction steps
- Relevant command/module
- Error message or screenshot
- Expected behavior
- Actual behavior

Do not include passwords, API keys, tokens, personal data, or other sensitive information in an issue.
